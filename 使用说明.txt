卡牌对决 · 电脑与手机联机版
================================

【电脑版】
双击「卡牌对决.exe」即可游玩（无需安装，内置服务器）。
窗口打开即进入游戏，菜单底部会显示本机地址。

【电脑与手机联机】
1. 电脑双击运行「卡牌对决.exe」（保持运行，不要关窗口）。
2. 手机连接与电脑同一个 WiFi。
3. 手机浏览器打开：http://电脑IP:8787
   （电脑IP 见游戏菜单底部或 exe 所在目录运行 ipconfig 查询）
4. 手机页面自动适配手机屏幕（竖屏：对手在上 → 战斗日志 → 自己与手牌在下）。
5. 电脑上点「局域网对战 → 创建房间」，手机上输入房间号加入即可。

【手机版打包 / 添加到主屏幕】
手机版为 PWA 网页，无需安装 APK：
- Chrome：菜单 →「添加到主屏幕」，之后可从桌面图标全屏启动。
- Safari(iOS)：分享 →「添加到主屏幕」。
- 注意：HTTP 局域网下部分浏览器的离线缓存(SW)不生效属正常，
  在线联机不受影响；同一局域网内直接访问即可。

【防火墙】
Windows 首次运行 exe 会弹出防火墙提示，务必勾选「专用网络」并允许，
否则手机无法连接。若已误点取消：控制面板 → Windows Defender 防火墙 →
允许应用通过防火墙 → 添加「卡牌对决」。

【功能】
- 真随机骰子决定先手（Web Crypto）
- 生命 / 固定防御 / 能量三属性，能量每回合回满
- 抽牌堆 / 弃牌堆规则（参考杀戮尖塔），每回合抽 5 张
- 角色自定义：名字 / 血量 / 防御 / 能量 / 介绍 / 图片 / 专属牌组
- 卡牌自定义：名字 / 费用 / 多个效果规则 / 特效(形式+颜色) / 图片，可增删
- 效果规则：伤害(含真伤) / 治疗 / 加防 / 加攻 / 破甲 / 卡费+ /
  百分比减伤 / 跳过回合 / 额外回合 / 抽牌 / 强制弃牌 / 能量调整
- 出牌动画：卡牌放大飞入中央，伤害红闪抖动(Minecraft式)、
  防御金、治疗绿、能量蓝等自定义特效
- 对战模式：单人 AI / 本地双人 / 局域网联机
- 自定义数据自动保存在浏览器本地

【目录文件】
卡牌对决.exe   可执行程序（双击运行）
index.html     游戏页面源码（响应式，电脑/手机共用）
main.py        exe 入口源码（内置服务器 + 窗口）
cardgame_server.py  独立服务器（网页调试用：python cardgame_server.py）
sw.js / icon-*.png  PWA 资源
build.bat       重新打包脚本

【重新打包】
build.bat 需要本机安装 Python 与依赖：
  pip install pywebview pyinstaller
